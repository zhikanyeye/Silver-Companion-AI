# Demo Script (3-5 minutes)

1. Start from the home selector and choose **长者** to introduce the elderly-friendly entry point with large text and clear actions.
2. In the elderly flow, open the anti-fraud assistant and show how suspicious message guidance is surfaced quickly in simple language.
3. Navigate to the community feed to demonstrate trusted neighborhood updates and practical local help content.
4. Return to home, choose **儿童**, and present the child dashboard as the family-facing view for quick status and communication context.
5. Open **设置** from home and briefly note where API key/model are configured for demo environment setup.
