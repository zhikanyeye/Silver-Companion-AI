# 银龄智伴首页精简与多端自适应设计文档

## 目标

删除首页当前信息价值较低的辅助说明卡片，让首屏回到“品牌主视觉 + 登录/注册入口”的清晰结构；同时补齐首页与登录页在手机、平板、桌面三类设备上的自适应节奏，减少拥挤、留白失衡和首屏层级分散的问题。

## 架构

首页继续使用现有 `BrandHero` 作为主视觉核心，但移除 `landing_page.dart` 中独立的 `_HeroSupportPanel` 辅助说明区，改为单核心区块布局。布局断点从当前“宽屏 / 非宽屏”二分，升级为手机、平板、桌面三档，分别控制最大宽度、边距、卡片圆角、内部间距与内容换行策略。

登录页延续现有单卡片入口形式，但同步引入三档自适应，重点调整内容区宽度、滚动留白、卡片内边距和顶部装饰尺寸，避免移动端过挤、平板端过窄、桌面端视觉悬空。

## 设计决策

### 首页

- 删除 `_HeroSupportPanel` 及其“更简单地开始陪伴 / 安心开始 / 一步完成”等辅助文案
- 保留顶部右侧登录 / 注册按钮组，但在窄屏下允许自然换行并保持触控尺寸
- 保留 `BrandHero` 作为首页唯一主内容区，强化品牌和核心能力表达
- 宽屏下居中展示单列主视觉，不再使用左右双栏，避免首屏信息被分散

### `BrandHero` 自适应

- 手机：压缩外边距、标题字号、段落间距、统计 chip 与能力卡片间距，优先保证首屏阅读连续性
- 平板：保持完整视觉结构，但缩小装饰圆形、卡片圆角和部分留白，避免页面显空
- 桌面：维持较强视觉表现，但控制最大宽度，避免主卡过宽导致文本行长过长
- 能力卡片与统计 chip 保持 `Wrap` 布局，但在窄屏下用更小的最小宽度和更紧凑的内边距减少断裂感

## 登录页自适应

- 手机：表单卡片满宽优先，减少左右留白，保证输入框、页签、按钮都稳定铺满
- 平板：增大卡片最大宽度，并降低“漂浮在中央的小卡片”感，让信息密度更接近正式产品登录页
- 桌面：保留当前中心单卡片结构，但优化上下留白和背景装饰比例，保持视觉平衡

## 交互与可用性

- 所有主要触控元素继续保持大于等于 44px 的可点击尺寸
- 保留现有轻量进场动画，但避免通过大幅位移影响窄屏稳定性
- 保持 `SingleChildScrollView`，确保小屏与横屏设备不会出现内容裁切
- 避免新增任何新的辅助模块，首屏只传达一个核心动作：进入登录或注册流程

## 测试策略

- 更新 `test/features/landing/landing_page_test.dart`，移除已删除辅助区块文案断言，转而验证首页只保留主视觉与登录/注册主入口
- 为首页增加至少一组窄屏 / 宽屏布局回归断言，确保被删除区块不再渲染
- 为登录页补充自适应回归测试，确认在较窄视口下表单主要元素仍可见并保持单卡片结构
- 运行相关 widget tests，并最终执行一次完整 `flutter test`

## 不在范围内

- 重做首页品牌文案
- 修改登录 / 注册的字段结构与业务流程
- 引入新的插画、图片资源或多栏营销模块
- 调整老人端 / 子女端页面风格
