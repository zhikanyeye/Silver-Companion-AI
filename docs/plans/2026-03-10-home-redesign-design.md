# 银龄智伴首页与主视觉重设计文档

## 目标

将当前过于简陋的角色选择页重设计为更适合竞赛答辩、同时兼顾未来 App 与小程序落地的品牌化首页，并统一角色命名为“老人端 / 子女端 / 平台端”。

## 设计方向

- 风格：温暖陪伴型
- 关键词：有温度、可信赖、适老化、家庭关怀、社区互助
- 平台兼容考虑：Web 端可展示，视觉组件也适合迁移到 App 与小程序

## 信息架构

首页由以下区域组成：

1. 顶部品牌区
   - Logo
   - 标题“银龄智伴”
   - 副标题“AI虚拟家人 + 社区互助的智慧养老平台”

2. 角色入口区
   - 老人端
   - 子女端
   - 平台端（演示入口/占位）

3. 核心能力区
   - AI陪伴
   - 反诈提醒
   - 社区互助
   - 亲情看板

4. 设置入口
   - 放在次级位置，不再占据首页主角色卡片位

## 视觉规范

- 主色：暖橙、珊瑚红、奶油白
- 背景：柔和渐变 + 大块留白
- 卡片：高圆角、大按钮、强触控感
- 字体表达：主标题有品牌感，正文清晰易读
- 图标语言：圆润、陪伴感强

## 交互原则

- 首页一眼能看懂角色分工
- 老人端入口最大、最显著
- 子女端突出“远程关怀”
- 平台端作为后续平台/社区管理视角预留
- 所有主要卡片都适配移动端纵向滚动布局

## 兼顾 App / 小程序 的实现约束

- 避免只适合桌面的横向布局
- 采用卡片式单列/双列结构，便于移动端复用
- 不依赖复杂 hover 交互
- 首屏组件需可映射到 Flutter App 和小程序组件体系

## 本轮实施范围

- 重做首页视觉与角色入口
- 统一角色文案
- 弱化首页中的“设置”，改为次级入口
- 尽量统一老人端、子女端页面的视觉语言

## 暂不包含

- 完整平台端后台功能实现
- 全量 Logo 深度接入所有端图标资源
- 小程序单独适配工程
