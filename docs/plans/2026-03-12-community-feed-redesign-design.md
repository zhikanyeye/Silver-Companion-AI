# 银龄智伴社区互助页改版设计文档

## 目标

将当前较为简单的社区互助页升级为更适合比赛展示与养老场景演示的品牌化社区页面，借鉴参考图中的“置顶信息区 + 推荐/最新切换 + 内容信息流”结构，但整体视觉、文案与交互保持银龄智伴的温暖陪伴风格。

## 设计原则

- 保留参考图的信息架构，不照搬论坛气质
- 优先适配银龄用户与子女查看场景，强调清晰、可信、易读
- 内容从“泛论坛帖子”转向“社区互助动态”
- 兼顾 Web 展示与未来 App / 小程序迁移

## 页面定位

社区页不再只是一个帖子列表，而是“银龄社区互助广场”。

它承担三个角色：

1. 告知用户社区近期有哪些值得注意的提醒
2. 展示邻里之间正在发生的帮助与回应
3. 给用户一个低门槛参与互助的入口

## 信息架构

页面由 4 个主要区块构成：

### 1. 社区头图区

- 页面标题：`社区互助`
- 品牌化副标题：如“看看邻里间正在发生的帮助与回应”
- 头图卡片继续使用温暖渐变与圆角容器，强化品牌统一性

### 2. 置顶提醒区

借鉴参考图顶部顶帖区，但改造为更贴合养老项目的“重要提醒”。

建议显示 3 条固定提醒：

- `社区公告`：如便民服务、物业通知、义诊安排
- `防诈提醒`：如陌生来电、保健品推销、转账提醒
- `本周活动`：如健康讲座、社区集体活动、志愿者服务

表现形式上更像轻量信息条或可点击提醒卡，而不是传统论坛置顶帖。

### 3. 内容切换区

保留参考图中的 `推荐 / 最新` 双入口。

- `推荐`：展示更典型、更适合演示的互助内容
- `最新`：展示按时间排序的近期动态

首轮实现以 UI 与轻量状态切换为主，不引入复杂筛选系统。

### 4. 互助动态流

信息流中的每条内容卡片改造成“邻里互助动态卡”，不采用传统论坛楼层样式。

每条卡片包含：

- 发起人头像徽章
- 姓名 / 昵称
- 身份说明（如楼栋住户、社区志愿者、服务站）
- 内容标题
- 内容摘要
- 地点与发布时间
- 响应状态（如“已有 3 人响应”“等待帮助中”）
- 轻量操作入口（如“查看详情”“我来帮忙”）

## 视觉语言

- 主色延续首页暖橙、珊瑚红、奶油白体系
- 背景使用柔和暖色渐变，不使用冷蓝论坛风
- 卡片大圆角、留白充足、弱边框、轻阴影
- 文本层次清晰，避免信息拥挤
- 推荐/最新切换做成轻量分段控件，选中态明确

## 内容风格

内容将聚焦养老社区真实场景，例如：

- 灯泡更换、搬运小物件
- 代取药、陪同看诊
- 活动报名、邻里问候
- 社区防诈提醒、健康科普

避免使用泛娱乐、年轻化论坛内容，以保证项目气质统一。

## 交互策略

- 保留当前 `发布互助` 浮动按钮，作为主要行动入口
- 推荐/最新切换允许在本地演示数据间切换
- 置顶提醒和卡片按钮首轮可用 snackbar 或占位反馈，不引入复杂详情页
- 保证触控区域足够大，适合移动端与老年用户演示

## 数据结构建议

为支持新的卡片结构，社区 mock 数据建议从当前的：

- 用户名
- 标签
- 地点
- 时间
- 正文

扩展为：

- 用户名
- 角色/身份说明
- 标签
- 标题
- 摘要
- 地点
- 时间
- 响应状态或响应人数
- 列表分类（推荐 / 最新）

## 测试与验收

社区页改版后，widget 测试至少验证以下内容：

- 页面标题与头图区文案存在
- 置顶提醒区存在并显示多条提醒
- `推荐` 与 `最新` 切换存在
- 互助动态卡按新结构渲染
- `发布互助` 按钮仍可点击并反馈

## 本轮范围

- 重做社区页头图区
- 新增置顶提醒区
- 新增推荐/最新切换样式与本地切换
- 重做信息流卡片结构
- 保留当前发布互助 FAB

## 暂不包含

- 社区详情页
- 真正的搜索、筛选、分页
- 后端数据接入
- 评论、点赞、关注等完整论坛能力
