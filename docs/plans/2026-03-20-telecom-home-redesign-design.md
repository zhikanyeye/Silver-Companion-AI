# 银龄智伴老人端与子女端电信风重设计文档

## 目标

把老人端和子女端从当前的温暖卡片页，升级为更接近电信服务产品的首页体验。老人端突出“大入口、强服务、易求助”，子女端突出“总览清晰、照护可追踪、提醒更有秩序”，并补齐手机、平板、桌面三档自适应。

## 总体方向

- 风格关键词：电信服务感、可信赖、清晰秩序、适老化、家庭关怀
- 视觉主轴：电信蓝为主、暖橙为辅，保留银龄智伴的温度感，不做冰冷政务风
- 布局原则：老人端操作优先，子女端信息优先；两端共享同一设计语言，但模块权重不同

## 老人端设计

### 信息架构

1. 顶部服务欢迎卡
   - 欢迎语
   - 今日陪伴提示
   - 快速状态标签
2. 常用服务入口区
   - `AI陪伴`
   - `一键求助`
   - `社区互助`
   - `活动`
3. 陪伴快捷入口
   - 将当前“小灵陪你聊聊天”融入主入口体系，保持高可达性

### 视觉与交互

- 手机端采用单列大卡片，图标更大、标题更醒目、触控范围更充足
- 平板与桌面可升为两列服务入口，减少纵向滚动压力
- `一键求助` 在视觉上比其他入口更突出，但不使用过于刺眼的告警红
- 保留当前聊天跳转与社区跳转路径，不改变功能行为

## 子女端设计

### 信息架构

1. 顶部家庭关怀总览卡
   - 今日整体状态
   - 关键照护摘要
2. 状态指标区
   - 健康
   - 情绪
   - 活跃互动等重点指标
3. 提醒时间线
   - 更清晰的时间标签、优先级和说明结构

### 视觉与交互

- 维持“稳重看板”而不是“业务大厅”风格
- 手机端单列阅读，平板/桌面端优先尝试左右分栏：左侧状态、右侧提醒
- 指标卡片强化信息层级，减少当前所有卡片视觉权重几乎相同的问题

## 自适应策略

- 手机：单列、16px 起正文、44px 以上触控区域、紧凑但不拥挤
- 平板：开始引入双列或分区布局，但核心操作仍在首屏上半区
- 桌面：增加容器最大宽度与分栏结构，避免内容过宽或过长
- 所有布局都保持 Flutter Web 与移动端一致，不依赖 hover 才能完成操作

## 测试策略

- 老人端：新增不同视口下主入口和求助位可见的回归测试，继续验证聊天与社区入口可达
- 子女端：新增不同视口下总览卡、状态卡、提醒时间线稳定存在的回归测试
- 所有改动按 TDD 执行：先改测试让其失败，再写最小实现使其通过
- 完成后运行相关 widget tests，并最终执行一次完整 `flutter test`

## 不在范围内

- 变更老人端 / 子女端的业务路由
- 新增真实后端数据接口
- 重做社区页和聊天页
- 引入新的图片资源或品牌素材包
